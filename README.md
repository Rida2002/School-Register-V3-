# School Register

A simple school attendance register built with **HTML, CSS and JavaScript**.

## Features

- Add students with their class and attendance status
- View total, present and absent students
- Automatic attendance percentage
- Search students by name or class
- Remove individual students
- Clear the entire register
- Data persists in the browser using `localStorage`
- Responsive layout for desktop and mobile

## How to Run

No installation is required.

1. Download or clone the repository.
2. Open `index.html` in a web browser.
3. Add students and manage the register.
